# LNG Tracker

Telegram-бот для мониторинга LNG-судов в заданных морских зонах.

## Что делает проект

- Периодически запрашивает данные по судам из внешнего API.
- Определяет вход LNG-судов в контролируемые зоны.
- Отправляет уведомления в Telegram пользователям из белого списка.
- Хранит текущее состояние и историю событий в SQLite.

## Стек

- Python 3.11+
- aiogram 3
- SQLAlchemy (async) + aiosqlite
- httpx
- loguru

## Установка

```bash
poetry install
```

## Настройка

Создайте файл `.env` в корне проекта:

```env
telegram_token=YOUR_TELEGRAM_BOT_TOKEN
chat_id=YOUR_ADMIN_TELEGRAM_ID
scan_interval=600
database_url=sqlite+aiosqlite:///data/monitor.db
```

Пояснения:

- `telegram_token` - токен Telegram-бота.
- `chat_id` - Telegram ID администратора (для команд админа).
- `scan_interval` - интервал сканирования в секундах.
- `database_url` - строка подключения к базе данных.

## Запуск

```bash
poetry run python src/main.py
```

## Логи

Логи пишутся:

- в файл `data/debug.log`
- в консоль

В логах отражаются:

- старт/остановка приложения
- инициализация БД
- результаты сканирования (количество активных судов, входы/выходы)
- статус рассылки уведомлений
- ошибки API и отправки сообщений

## Команды бота

- `/start` - регистрация пользователя
- `/status` - текущие активные суда в зонах
- `/stats` - статистика входов за 24 часа
- `/help` - список команд
- `/approve <id>` - выдать доступ пользователю (админ)
- `/clear_db` - очистка таблиц состояния и истории (админ)

## Структура проекта

- `src/main.py` - точка входа
- `src/lng_tracker/services/engine.py` - движок мониторинга
- `src/lng_tracker/services/notifier.py` - отправка уведомлений
- `src/lng_tracker/bot/handlers.py` - команды Telegram-бота
- `src/lng_tracker/database/` - модели и подключение к БД

## Примечания

- Каталог `data/` создается автоматически при запуске.
- При первом запуске таблицы в базе создаются автоматически.
